## Questions

1. Software is said to:
   (a) wear out (b) deteriorate through change (c) be manufactured (d) never need maintenance

<details><summary>Answer</summary>(b) Lesson 1.</details>

2. Which model has a test phase paired with each development phase?
   (a) waterfall (b) V-model (c) spiral (d) Big Bang

<details><summary>Answer</summary>(b) Lesson 1.</details>

3. In Scrum, the person who owns and prioritises the backlog is the:
   (a) Scrum master (b) product owner (c) team lead (d) customer only

<details><summary>Answer</summary>(b) Lesson 1.</details>

4. An SRS should be:
   (a) ambiguous to allow flexibility (b) verifiable and traceable (c) written in code (d) secret

<details><summary>Answer</summary>(b) Lesson 1.</details>

5. Which is a requirements elicitation technique?
   (a) regression testing (b) ethnography (observation) (c) COCOMO (d) refactoring

<details><summary>Answer</summary>(b) Lesson 1.</details>

6. In a DFD, a process must have:
   (a) only inputs (b) only outputs (c) at least one input and one output (d) a data store

<details><summary>Answer</summary>(c) Lesson 2.</details>

7. A child DFD having the same inputs and outputs as its parent is called:
   (a) levelling (b) balancing (c) normalising (d) partitioning

<details><summary>Answer</summary>(b) Lesson 2.</details>

8. "Pay penalty" happens only when a payment is late. Its relation to "Pay tax" is:
   (a) «include» (b) «extend» (c) generalisation (d) association

<details><summary>Answer</summary>(b) Lesson 2.</details>

9. The diagram that shows object interactions ordered in time:
   (a) class (b) sequence (c) deployment (d) component

<details><summary>Answer</summary>(b) Lesson 2.</details>

10. Which is a structural UML diagram?
    (a) activity (b) state machine (c) class (d) sequence

<details><summary>Answer</summary>(c) Lesson 2.</details>

11. Modules sharing global variables have:
    (a) data coupling (b) stamp coupling (c) common coupling (d) no coupling

<details><summary>Answer</summary>(c) Lesson 3.</details>

12. Grouping initialisation tasks because they run at start-up is:
    (a) functional cohesion (b) temporal cohesion (c) sequential cohesion (d) logical cohesion

<details><summary>Answer</summary>(b) Lesson 3.</details>

13. A three-tier architecture separates:
    (a) presentation, application logic, data (b) client, network, cable (c) design, code, test (d) unit, integration, system

<details><summary>Answer</summary>(a) Lesson 3.</details>

14. MVC separates:
    (a) model, view, controller (b) memory, virtual, cache (c) module, version, configuration (d) method, variable, class

<details><summary>Answer</summary>(a) Lesson 3.</details>

15. Component-based software engineering builds systems from:
    (a) scratch only (b) reusable components with defined interfaces (c) formal proofs (d) prototypes only

<details><summary>Answer</summary>(b) Lesson 3.</details>

16. Testing done by users at the developer's site is:
    (a) beta (b) alpha (c) unit (d) smoke

<details><summary>Answer</summary>(b) Lesson 4.</details>

17. Bottom-up integration uses:
    (a) stubs (b) drivers (c) both (d) neither

<details><summary>Answer</summary>(b) Lesson 4.</details>

18. A program with 4 decision points (simple conditions) has cyclomatic complexity:
    (a) 3 (b) 4 (c) 5 (d) 6

<details><summary>Answer</summary>(c) P + 1. Lesson 4.</details>

19. Input valid range 1–100. Boundary values to test include:
    (a) 50 only (b) 0, 1, 100, 101 (c) 25, 75 (d) −100, 1000

<details><summary>Answer</summary>(b) Lesson 4.</details>

20. Static testing includes:
    (a) load testing (b) code inspections and walkthroughs (c) beta testing (d) unit tests run in CI

<details><summary>Answer</summary>(b) Lesson 4.</details>

21. Basic COCOMO organic effort for 10 KLOC is about (2.4 × 10^1.05):
    (a) 24 PM (b) 26.9 PM (c) 10 PM (d) 50 PM

<details><summary>Answer</summary>(b) Lesson 5.</details>

22. Function points measure:
    (a) lines of code (b) functionality from the user's view (c) defects (d) team size

<details><summary>Answer</summary>(b) Lesson 5.</details>

23. CMMI level 4 is:
    (a) defined (b) optimising (c) quantitatively managed (d) managed

<details><summary>Answer</summary>(c) Lesson 5.</details>

24. Adding a new report requested by users is:
    (a) corrective (b) adaptive (c) perfective (d) preventive maintenance

<details><summary>Answer</summary>(c) Lesson 5.</details>

25. The body that approves or rejects change requests is the:
    (a) SQA team (b) change control board (c) Scrum master (d) test team

<details><summary>Answer</summary>(b) Lesson 5.</details>
