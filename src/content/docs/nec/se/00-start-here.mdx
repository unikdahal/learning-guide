This course covers **NEC 8.1–8.3** and **Lok Sewa Computer Engineer unit 8 (software engineering / system analysis and design)**, and it prepares you for **Section D's 20-mark case study**, the single biggest question on Paper II. For **Computer Officer**, system analysis and design is about 10% of Paper II.

<Aside type="note" title="Industry practice vs the textbook">
You ship software, so none of this is new in spirit. But the exam uses **Sommerville and Pressman vocabulary** (V-model, SRS, cohesion types, cyclomatic complexity, COCOMO, CMMI levels) and expects **diagrams drawn by hand with correct notation** — DFD symbols and levelling rules, `include` vs `extend`, sequence-diagram messages. This course drills exactly those.
</Aside>

All diagrams use **one running example** — an **online revenue (tax) payment system**, a reported CE 2079 case study — so you can see how feasibility, DFDs, use cases, sequence diagrams and the ER model fit together in one answer.
