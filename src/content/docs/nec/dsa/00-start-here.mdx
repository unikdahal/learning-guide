This course covers **NEC 7.1–7.2** and **Lok Sewa Computer Engineer unit 7 (data structures and algorithms)**; for Computer Officer it is the DSA 8% of Paper II.

<Aside type="note" title="You already know this — the course is about exam form">
You write and reason about these structures for a living. What the exam wants is different: **hand traces** (stack contents while converting infix to postfix, an AVL rotation, a probe sequence, a Prim table), **textbook definitions and complexities**, and **structured written answers**. So each lesson is short on "what is a stack" and long on traces you can reproduce on paper in eight minutes. Code is in C++.
</Aside>
