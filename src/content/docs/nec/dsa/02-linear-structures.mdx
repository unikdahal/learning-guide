## 1. Stack — LIFO

Operations: **push**, **pop**, **peek/top**, isEmpty, isFull — all **O(1)**. Errors: **overflow** (push on full), **underflow** (pop on empty).

```cpp
class Stack {
    int a[100];
    int top = -1;
public:
    void push(int x) { if (top == 99) throw std::overflow_error("overflow"); a[++top] = x; }
    int pop() { if (top == -1) throw std::underflow_error("underflow"); return a[top--]; }
    int peek() const { return a[top]; }
    bool empty() const { return top == -1; }
};
```

**Applications:** function calls and recursion, expression conversion and evaluation, parenthesis matching, undo, backtracking (maze, DFS), browser back button.

## 2. Infix, postfix, prefix

- **Infix** A + B (operator between — needs precedence and brackets).
- **Postfix (reverse Polish)** A B + — no brackets needed; easy for machines to evaluate with one stack.
- **Prefix (Polish)** + A B.

Precedence: `^` (right-associative) > `* /` > `+ −` (left-associative).

### Infix → postfix algorithm

Scan left to right:
1. **Operand** → output.
2. **(** → push.
3. **)** → pop to output until **(**; discard both brackets.
4. **Operator** → while the stack top has **higher precedence, or equal precedence and is left-associative**, pop it to output; then push the operator.
5. At the end, pop everything to output.

**Worked: A + B * (C − D) / E**

| Symbol | Stack (bottom → top) | Output |
| --- | --- | --- |
| A | | A |
| + | + | A |
| B | + | A B |
| * | + * | A B |
| ( | + * ( | A B |
| C | + * ( | A B C |
| − | + * ( − | A B C |
| D | + * ( − | A B C D |
| ) | + * | A B C D − |
| / | + / | A B C D − * |
| E | + / | A B C D − * E |
| end | | **A B C D − * E / +** |

At `/`, the top `*` has equal precedence and is left-associative, so `*` is popped first.

**Infix → prefix:** reverse the infix (swapping `(` and `)`), convert to postfix (treat equal precedence as *not* popping), then reverse the result. Here: **+ A / * B − C D E**.

### Evaluating postfix

Operand → push. Operator → pop **two** (first popped is the **right** operand), apply, push the result.

**Worked: 5 3 2 * + 4 −**

| Symbol | Action | Stack |
| --- | --- | --- |
| 5, 3, 2 | push | 5 3 2 |
| * | 3 * 2 = 6 | 5 6 |
| + | 5 + 6 = 11 | 11 |
| 4 | push | 11 4 |
| − | 11 − 4 = 7 | **7** |

(For prefix, scan right to left; the first popped is the **left** operand.)

## 3. Queue — FIFO

Insert at the **rear** (enqueue), remove from the **front** (dequeue).

**Linear array queue problem:** after some dequeues, the front slots are wasted — rear reaches the end while the array has space.

**Circular queue** wraps around with modulo:
- enqueue: `rear = (rear + 1) % N`
- dequeue: `front = (front + 1) % N`
- **Full** when `(rear + 1) % N == front` (one slot is left empty to tell full from empty) — or keep a count.
- **Empty** when `front == rear` (in the one-slot-empty convention) or count == 0.

```cpp
class CircularQueue {
    std::vector<int> a; int front = 0, rear = 0;
public:
    explicit CircularQueue(int n) : a(n) {}
    bool full() const  { return (rear + 1) % (int)a.size() == front; }
    bool empty() const { return front == rear; }
    void enqueue(int x) { if (full()) throw std::overflow_error("full"); a[rear] = x; rear = (rear + 1) % a.size(); }
    int dequeue() { if (empty()) throw std::underflow_error("empty"); int x = a[front]; front = (front + 1) % a.size(); return x; }
};
```

**Variants:** **deque** (insert/delete at both ends; input-restricted and output-restricted), **priority queue** (remove the highest-priority element — implemented with a heap, O(log n)). **Applications:** CPU and disk scheduling, BFS, print spooling, buffers.

## 4. Linked lists

Nodes with data + pointer(s); dynamic size; O(1) insertion/deletion once the position is known; no random access (O(n) to reach the k-th node); extra memory for pointers.

```cpp
struct Node { int data; Node* next; };

void insertFront(Node*& head, int x) { head = new Node{x, head}; }

void insertAfter(Node* p, int x) { p->next = new Node{x, p->next}; }

void deleteKey(Node*& head, int key) {
    Node** cur = &head;                      // pointer to the link to rewrite
    while (*cur && (*cur)->data != key) cur = &(*cur)->next;
    if (*cur) { Node* t = *cur; *cur = t->next; delete t; }
}

Node* reverse(Node* head) {                  // classic interview and exam favourite
    Node* prev = nullptr;
    while (head) { Node* nx = head->next; head->next = prev; prev = head; head = nx; }
    return prev;
}
```

| Type | Links | Notes |
| --- | --- | --- |
| **Singly** | next | traverse one way |
| **Doubly** | prev, next | traverse both ways; delete a node given only a pointer to it in O(1) |
| **Circular singly** | last → first | any node can start a full traversal; round-robin scheduling |
| **Circular doubly** | last ↔ first | **head→prev is the last node**; last→next is the head |

**Doubly linked deletion of node p:** `p->prev->next = p->next; p->next->prev = p->prev; delete p;`

| Operation | Array | Linked list |
| --- | --- | --- |
| Access k-th | O(1) | O(n) |
| Insert/delete at front | O(n) (shift) | O(1) |
| Memory | contiguous, fixed (or amortised resize) | scattered, extra pointer per node |
| Cache behaviour | excellent | poor |

**Polynomial representation:** each node holds (coefficient, exponent); adding two polynomials merges the lists in exponent order. **Sparse matrices** use triplets (row, column, value) or linked lists.

**Question.** Write an algorithm to convert an infix expression to postfix. Convert ((A + B) * C − (D − E)) ^ (F + G) showing the stack at each step.

<details>
<summary>Model answer</summary>

**Algorithm (using an operator stack).**
1. Scan the infix expression from left to right.
2. If the symbol is an operand, append it to the output.
3. If it is `(`, push it.
4. If it is `)`, pop and output operators until `(` is popped; discard the brackets.
5. If it is an operator, pop and output operators from the stack while the top has higher precedence (or equal precedence and the incoming operator is left-associative); then push the incoming operator.
6. After the scan, pop and output all remaining operators.

Precedence: ^ (right-associative) > *, / > +, −.
