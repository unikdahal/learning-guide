This course covers **NEC Chapter 3 (ACtE03, about 10 questions)** and **Lok Sewa Computer Engineer unit 6 (structured and object-oriented programming)**; Computer Officer adds a little Java and language translators, covered in lesson 6.

<Aside type="note" title="Why a coder still needs this">
You write code daily, so the risk is not ignorance — it's **exam trivia that production code avoids**: integer division and `%` with negatives, `switch` fall-through, `sizeof` on arrays vs pointers, struct padding, constructor/destructor order, which `f()` overload is chosen, `x++` vs `++x`, manipulators like `setfill`. NEC asks these as one-line MCQs. **Every output on these pages was produced by compiling and running the code** (gcc/g++ 13, 64-bit Linux), so you can trust them — sizes like `sizeof(int*)` are stated for that platform.
</Aside>
