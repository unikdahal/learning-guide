## 1. From voltage to 0 and 1

A digital circuit uses just two voltage ranges. In **positive logic**, HIGH = 1 and LOW = 0 (the usual convention); in **negative logic**, the opposite. For 5 V TTL, roughly 0–0.8 V reads as 0 and 2–5 V as 1; the gap between is forbidden ([lesson 10](/learning-guide/nec/digital/10-logic-families-memory-adc/) has exact levels). Because only two levels must be told apart, digital circuits shrug off noise that would corrupt an analog signal.

## 2. The gates

Try each one — toggle A and B:

<GateLab />

| Gate | Expression | Output is 1 when… |
| --- | --- | --- |
| AND | Y = A·B | all inputs are 1 |
| OR | Y = A + B | any input is 1 |
| NOT | Y = A' | input is 0 |
| NAND | Y = (A·B)' | any input is 0 |
| NOR | Y = (A + B)' | all inputs are 0 |
| XOR | Y = A ⊕ B = A'B + AB' | inputs differ (odd number of 1s) |
| XNOR | Y = (A ⊕ B)' = AB + A'B' | inputs are equal |

A **buffer** (Y = A) is a NOT without the inversion — used to boost drive strength; a **tri-state buffer** adds an enable that can disconnect its output (high impedance, "Z") so many devices can share a bus.

## 3. Universal gates

**NAND alone** (or **NOR alone**) can build any circuit. That's why early chips and today's standard-cell libraries lean on them.

| To build | NAND gates | How (NAND) | NOR gates |
| --- | --- | --- | --- |
| NOT | 1 | tie both inputs together | 1 |
| AND | 2 | NAND then NOT | **3** |
| OR | 3 | invert each input, then NAND (De Morgan) | 2 |
| XOR | 4 | — | 5 |
| XNOR | 5 | — | 4 |

**Why AND from NOR needs 3:** De Morgan says `A·B = (A' + B')'`. Two NORs make A' and B'; a third NOR combines them. That answers the model-paper question.

## 4. Gate facts examiners like

- AND/OR/NAND/NOR/XOR can have more than two inputs; XOR with many inputs gives 1 for an **odd** number of 1s → a **parity generator**.
- Any unused AND/NAND input should be tied HIGH; unused OR/NOR inputs tied LOW (floating CMOS inputs misbehave).
- **Bubbled gates:** a NAND is equivalent to an OR with inverted inputs; a NOR is equivalent to an AND with inverted inputs (De Morgan, next lesson).

## Lok Sewa: write it (5 marks · 8 minutes)

**Question.** Why are NAND and NOR called universal gates? Realise NOT, AND and OR using NAND gates only.

<details>
<summary>Model answer</summary>

A gate is **universal** if any Boolean function can be implemented using only that gate type. Since every function can be written with AND, OR and NOT, it is enough to build these three from NAND (or from NOR). This matters in practice: an IC family can be built from one gate type (NAND is cheapest in CMOS and TTL).

**Using NAND only** (Y = (AB)'): *(draw each circuit)*
1. **NOT:** tie both inputs together: (A·A)' = **A'**.
2. **AND:** NAND followed by a NAND-inverter: ((AB)')' = **AB** — two gates.
3. **OR:** invert each input with a NAND, then NAND them: (A'·B')' = A + B by De Morgan — **three gates**.

**Using NOR only** (dual): NOT = (A + A)'; OR = NOR followed by an inverter; AND = NOR of the inverted inputs: (A' + B')' = AB.

| Function | NAND gates needed | NOR gates needed |
| --- | --- | --- |
| NOT | 1 | 1 |
| AND | 2 | 3 |
| OR | 3 | 2 |
| XOR | 4 | 5 |

</details>
