**Goal:** minimise any function of up to four variables, with don't-cares, into SOP or POS, in a few minutes.

<Aside type="note" title="Where this scores for you">
**NEC 2.1** ("truth table to Karnaugh map"). **Lok Sewa CE 3.3** — "Simplify using a K-map and draw the logic circuit" is one of the most common 5-mark digital questions.
</Aside>

## 1. The idea

A K-map is a truth table **rearranged** so that neighbouring cells differ in exactly **one** variable. Neighbouring 1s can then be combined: the variable that changes between them drops out (`AB + AB' = A`).

To make every neighbour differ by one bit, rows and columns are labelled in **Gray code**: **00, 01, 11, 10** — not 00, 01, 10, 11.

## 2. Layouts

- **2 variables:** 2 × 2.
- **3 variables:** 2 × 4 (A on rows; BC on columns: 00 01 11 10).
- **4 variables:** 4 × 4 (AB on rows; CD on columns).

Cell for minterm m: for 4 variables, row = AB, column = CD. Note that row 11 comes **before** row 10, so m12–m15 are on the third row and m8–m11 on the fourth.

## 3. Grouping rules

1. Group only 1s (for SOP).
2. Group sizes must be **powers of two**: 1, 2, 4, 8, 16.
3. Groups must be **rectangles** (squares or lines) — no diagonals or L-shapes.
4. Make every group **as large as possible** (bigger group → fewer literals).
5. Use **as few groups as possible**; overlapping is allowed.
6. The map **wraps around**: the left and right edges are neighbours, and so are the top and bottom. The four **corners** form a group of four.
7. For each group, keep only the variables that **don't change** within it.

A group of 2ⁿ cells eliminates n variables: in a 4-variable map, a pair leaves 3 literals, a quad 2, an octet 1.

## 4. A full example

**F(A, B, C, D) = Σm(0, 2, 5, 7, 8, 10, 13, 15)**

- **Centre quad** m5, m7, m13, m15: B = 1 and D = 1 throughout; A and C change → **BD**.
- **Corner quad** m0, m2, m8, m10: B = 0 and D = 0 throughout → **B'D'**.

**F = BD + B'D'** — which is B XNOR D. Eight minterms collapse to two terms.

## 5. Don't-care conditions

Some input combinations never occur (e.g. BCD codes 10–15) or their output doesn't matter. Mark them **X** (or d). Include an X in a group **if it helps** make the group bigger; otherwise ignore it.

**Example.** F = Σm(1, 3, 7, 11, 15) + d(0, 2, 5).
- Column CD = 11 holds m3, m7, m15, m11 → quad **CD**.
- m1 is left. Grouping it with m3 and don't-cares m5, m7 gives the quad **A'D**. (Using don't-cares m0, m2 instead gives **A'B'** — equally minimal.)
- **F = CD + A'D** (or CD + A'B'). More than one minimal answer can be correct.

## 6. POS from the zeros

Group the **0s** instead, write each group as a sum term with variables **complemented** (a variable that's 1 in the group appears as `X'`; 0 appears as `X`), and AND the groups. Or: find the SOP of F' from the 0s, then apply De Morgan.

## 7. Beyond four variables

Five- and six-variable maps exist but are awkward. The **Quine–McCluskey (tabular) method** does the same job systematically and can be programmed — the basis of logic-synthesis tools.

## Lok Sewa: write it (5 marks · 8 minutes)

**Question.** Simplify F(A, B, C, D) = Σm(0, 1, 2, 5, 8, 9, 10) using a K-map and draw the logic circuit.

<summary>Model answer</summary>

*(Draw the 4 × 4 map with rows AB = 00, 01, 11, 10 and columns CD = 00, 01, 11, 10; place 1s at m0, m1, m2, m5, m8, m9, m10.)*

**Groups.**
1. m0, m1, m8, m9 (rows 00 and 10, columns 00 and 01): B = 0, C = 0 → **B'C'**.
2. m0, m2, m8, m10 (four corners): B = 0, D = 0 → **B'D'**.
3. m5 remains; pair it with m1 (row 01 col 01 with row 00 col 01): A = 0, C = 0, D = 1 → **A'C'D**.

**Result.** F = B'C' + B'D' + A'C'D.

**Circuit.** Three AND gates (inputs from inverters as needed) feeding one 3-input OR gate *(draw)*; or the equivalent NAND–NAND network.
