## 1. Logic-family parameters

- **Noise margin:** how much noise a signal can pick up and still be read correctly. NM_H = V_OH(min) − V_IH(min); NM_L = V_IL(max) − V_OL(max).
- **Fan-out:** how many inputs one output can drive. **Fan-in:** number of inputs a gate has.
- **Propagation delay:** input change → output change (ns).
- **Power dissipation** per gate.
- **Speed–power product** = delay × power (picojoules) — lower is better.

## 2. TTL, CMOS, ECL

**TTL (transistor–transistor logic), 74xx:** bipolar transistors, 5 V. Standard levels: V_IL ≤ 0.8 V, V_IH ≥ 2.0 V, V_OL ≤ 0.4 V, V_OH ≥ 2.4 V → **noise margin 0.4 V**. Fan-out ≈ 10. Totem-pole output; open-collector variants allow wired-AND and pull-ups.

**CMOS (4000, 74HC/HCT…):** complementary MOSFETs ([electronics lesson 30](/learning-guide/nec/electronics/30-fet-mosfet-cmos/)). Near-zero static power, wide supply range, high noise margin (≈ 30–45% of V_DD), very large fan-out. Power rises with frequency (CV²f). Dominant today.

**ECL (emitter-coupled logic):** transistors never saturate, so it's the **fastest** bipolar family — but uses the most power and a negative supply. Used in very-high-speed niches.

| | TTL | CMOS | ECL |
| --- | --- | --- | --- |
| Speed | medium | medium → very high (modern) | **highest** |
| Static power | moderate | **lowest** | highest |
| Noise margin | 0.4 V | **high** | low |
| Fan-out | ~10 | **very high** | high |
| Supply | 5 V | 1–15 V | −5.2 V |

(RTL and DTL are historical predecessors.)

## 3. Memory devices

**Classification:**
- **Volatile** (loses data without power): **SRAM** (flip-flop cells — fast, 6 transistors per bit, used for **cache**) and **DRAM** (one transistor + one capacitor per bit — dense and cheap, but leaks so must be **refreshed** every few ms; used for **main memory**).
- **Non-volatile:** **mask ROM** (fixed at manufacture), **PROM** (programmed once by blowing fuses), **EPROM** (erased by **UV light** through a quartz window), **EEPROM** (erased **electrically**, byte by byte — charge is pushed onto or pulled off a **floating gate** through a very thin oxide), **Flash** (EEPROM erased in blocks — SSDs, USB drives, BIOS chips).

**Organisation.** A chip described as **2ᵏ × m** has 2ᵏ locations of m bits: **k address lines, m data lines**.
- 2K × 8 → 2,048 = 2¹¹ → **11 address lines**, 8 data lines.
- 64K × 8 (the 8085's whole space) → 16 address lines.
- Building bigger memory: chips side by side widen the word; more chips plus a decoder add locations (lesson 13).

## 4. DAC — digital to analog

Converts an n-bit number into a proportional voltage.

- **Resolution** = V_ref / 2ⁿ (the step per LSB). 8-bit, 10 V reference → 10/256 ≈ **39 mV**.
- **Binary-weighted resistor DAC:** resistors R, 2R, 4R, … into an op-amp summer. Simple, but needs a huge spread of precise values.
- **R–2R ladder DAC:** only two resistor values — easy to make accurate. The most common type.

## 5. ADC — analog to digital

| Type | How | Speed | Use |
| --- | --- | --- | --- |
| **Flash (parallel)** | 2ⁿ − 1 comparators at once | **fastest** | video, oscilloscopes |
| **Successive approximation (SAR)** | binary search, one bit per clock (n clocks) | medium | the common general-purpose type, microcontrollers |
| **Dual-slope (integrating)** | integrates input, then de-integrates a reference | slow | digital multimeters (rejects noise, accurate) |
| **Counter / ramp** | counts up until a DAC output passes the input | slow, variable | teaching |

**Sampling theorem (Nyquist):** to reconstruct a signal, sample at least **twice** its highest frequency (f_s ≥ 2f_max) — CD audio samples at 44.1 kHz for 20 kHz audio. Also on the Lok Sewa communications unit.

**Quantisation error:** ±½ LSB — the unavoidable rounding error.

## Lok Sewa: write it (10 marks · 16 minutes)

**Question.** Compare TTL and CMOS logic families. Explain the working of a successive-approximation ADC.

<details>
<summary>Model answer</summary>

**TTL vs CMOS.**

| Parameter | TTL (74xx) | CMOS (4000, 74HC) |
| --- | --- | --- |
| Devices | bipolar transistors | complementary n- and p-MOSFETs |
| Supply | 5 V ± 5% | 3–15 V (4000), 2–6 V (HC) |
| Static power | milliwatts per gate | nanowatts (≈ zero); rises with frequency (CV²f) |
| Noise margin | ≈ 0.4 V | ≈ 30–45% of VDD — higher |
| Fan-out | ≈ 10 | very large (≥ 50) |
| Speed | fast (standard ≈ 10 ns) | slower in the 4000 series; modern CMOS is very fast |
| Input | current-driven; unused inputs float high | voltage-driven, very high impedance; unused inputs must be tied |
| Sensitivity | robust | static-sensitive |
| Density | lower | very high — used in VLSI |

**Successive-approximation ADC.** *(Draw: analog input → comparator ← DAC ← SAR register ← control/clock; digital output from the SAR.)*
1. The successive-approximation register (SAR) starts by setting the **MSB = 1**, others 0.
2. The DAC converts this trial code to a voltage, which the **comparator** compares with the input.
3. If the DAC voltage exceeds the input, the bit is reset to 0; otherwise it stays 1.
4. The next bit is tried the same way — a **binary search** — until all n bits are decided.
5. The SAR then holds the digital output; an end-of-conversion signal is raised.

**Example** (4-bit, Vref = 16 V, input 10.3 V): try 1000 (8 V) → keep; 1100 (12 V) → too high, clear; 1010 (10 V) → keep; 1011 (11 V) → clear → result **1010**.

**Features:** conversion time n clock cycles, fixed and independent of the input; medium speed and resolution; the most common general-purpose ADC (microcontrollers). Faster: flash; more accurate and noise-immune: dual-slope.

</details>
