## 1. What a microprocessor is

A **microprocessor** is a CPU on one chip: it fetches instructions from memory, decodes them and executes them. Add memory and I/O and you have a **microcomputer**. A **microcontroller** puts CPU, memory and I/O on one chip (8051, AVR, ARM Cortex-M).

Three buses connect the CPU to everything:
- **Address bus** (one-way, CPU → out): which location.
- **Data bus** (two-way): the value.
- **Control bus**: read/write/timing signals (RD', WR', IO/M', ALE).

**Fetch–decode–execute** repeats forever: PC → address bus → instruction read → PC incremented → decode → execute.

## 2. 8085 at a glance

- 8-bit microprocessor by Intel (1976), **40-pin DIP**, single **+5 V** supply.
- **8-bit data bus, 16-bit address bus → 64 KB** (2¹⁶) of memory.
- Clock up to **3 MHz** (crystal at 6 MHz, divided by 2 internally).
- The lower address byte and the data bus share pins **AD0–AD7** (**multiplexed**); the **ALE** signal tells an external latch (74LS373) when AD0–AD7 carry an address.
- 74 instructions (246 opcodes); 5 hardware interrupts (lesson 14).

## 3. Registers

| Register | Size | Role |
| --- | --- | --- |
| **A (accumulator)** | 8-bit | one operand and the result of every arithmetic/logic operation |
| B, C, D, E, H, L | 8-bit each | general purpose; usable as **pairs BC, DE, HL** (16-bit) |
| **HL** | 16-bit pair | the **memory pointer** — `M` in instructions means "the byte at address HL" |
| **PC** (program counter) | 16-bit | address of the **next** instruction |
| **SP** (stack pointer) | 16-bit | top of the stack in RAM |
| Flag register | 8-bit (5 used) | status of the last ALU result |
| Instruction register/decoder, temp register | — | internal; not programmer-accessible |

### Flags (S Z X AC X P X CY)

| Flag | Set to 1 when the result… |
| --- | --- |
| **S** (sign) | has bit 7 = 1 (negative in two's complement) |
| **Z** (zero) | is zero |
| **AC** (auxiliary carry) | had a carry from bit 3 to bit 4 (used by DAA for BCD) |
| **P** (parity) | has an **even** number of 1s |
| **CY** (carry) | produced a carry out of bit 7 (or a borrow) |

Example: A = 9AH + 6FH = 109H → A = 09H. Flags: CY = 1, S = 0, Z = 0, P = 1 (09H = 0000 1001, two 1s → even), AC = 1 (A + F = 19H carries out of bit 3).

## 4. Addressing modes

How an instruction finds its operand:

| Mode | Example | Operand is |
| --- | --- | --- |
| **Immediate** | `MVI A, 32H` | in the instruction itself |
| **Register** | `MOV B, C` | in a register |
| **Direct** | `LDA 2050H` | at a 16-bit address given in the instruction |
| **Register indirect** | `MOV A, M` / `LDAX B` | at the address held in a register pair |
| **Implied (implicit)** | `CMA`, `RAL` | implied by the opcode (usually A) |

## 5. Instruction groups

| Group | Examples |
| --- | --- |
| **Data transfer** (no flags affected) | MOV, MVI, LDA, STA, LDAX, STAX, LXI, LHLD, SHLD, XCHG, IN, OUT, PUSH, POP |
| **Arithmetic** | ADD, ADI, ADC, SUB, SUI, SBB, INR, DCR, INX, DCX, DAD, DAA |
| **Logical** | ANA, ANI, ORA, XRA, CMP, CPI, CMA, CMC, STC, RLC, RRC, RAL, RAR |
| **Branch** | JMP, JZ/JNZ, JC/JNC, JP/JM, JPE/JPO, CALL, RET, RST n |
| **Machine control** | HLT, NOP, EI, DI, SIM, RIM |

Traps the examiner loves:
- **INX/DCX** (16-bit) affect **no flags**; INR/DCR (8-bit) affect all **except CY**.
- **CMP B** subtracts B from A without storing: A < B → CY = 1; A = B → Z = 1; A > B → both 0.
- Instruction sizes: 1 byte (MOV B,C), 2 bytes (MVI A,32H), 3 bytes (LDA 2050H, JMP 2000H).

## 6. Timing

- **T-state:** one clock period.
- **Machine cycle:** one bus operation — opcode fetch (4–6 T), memory read (3 T), memory write (3 T), I/O read/write (3 T).
- **Instruction cycle:** all machine cycles of one instruction. `MVI A, 32H` = opcode fetch + memory read = 4 + 3 = **7 T-states**. `LDA 2050H` = fetch + read + read + read = 4 + 3 + 3 + 3 = **13 T**. At 3 MHz, 1 T ≈ 0.33 µs.
- The **timing diagram** for opcode fetch: ALE high in T1 (latch the low address), RD' low in T2–T3, decode in T4.

## 7. Programs

**Add two numbers at 2050H and 2051H; store the 16-bit result at 2052H (low) and 2053H (carry):**

```text
LDA 2050H    ; A ← [2050]
MOV B, A     ; B ← A
LDA 2051H    ; A ← [2051]
ADD B        ; A ← A + B, CY set on overflow
STA 2052H    ; store low byte
MVI A, 00H   ; A ← 0 (MVI does not touch flags)
ACI 00H      ; A ← 0 + 0 + CY
STA 2053H    ; store carry
HLT
```

**Find the largest of N numbers; N at 2050H, data from 2051H, result to 2060H:**

```text
      LXI H, 2050H   ; HL → count
      MOV C, M       ; C ← N
      INX H          ; HL → first number
      MOV A, M       ; A ← first number (current max)
      DCR C          ; N − 1 comparisons left
LOOP: INX H
      CMP M          ; A − M
      JNC SKIP       ; CY = 0 → A ≥ M, keep A
      MOV A, M       ; new max
SKIP: DCR C
      JNZ LOOP
      STA 2060H
      HLT
```

(For the smallest, change JNC to JC.)

**Count the 1s in a byte at 2050H** — the shift-and-check pattern:

```text
      LDA 2050H
      MVI B, 00H     ; count
      MVI C, 08H     ; 8 bits
NEXT: RAR            ; bit 0 → CY
      JNC ZERO
      INR B
ZERO: DCR C
      JNZ NEXT
      MOV A, B
      STA 2051H
      HLT
```

**Question.** Draw the functional block diagram of the 8085 microprocessor and explain its main units. Describe its flag register.

<details>
<summary>Model answer</summary>

**8085.** An 8-bit, 40-pin NMOS microprocessor on +5 V with an 8-bit data bus and 16-bit address bus (64 KB), clocked at 3 MHz. *(Draw the block diagram.)*

**1. ALU group.** Accumulator (8-bit; holds one operand and the result), temporary register (holds the other operand, not accessible), ALU (add, subtract, logic, rotate, compare), and flag register.

**2. Register array.** Six 8-bit general-purpose registers B, C, D, E, H, L, usable as pairs BC, DE, HL; HL serves as the memory pointer. 16-bit **stack pointer** (top of stack) and **program counter** (address of next instruction). Increment/decrement address latch.

**3. Instruction register and decoder.** Holds the fetched opcode and decodes it into internal control signals.

**4. Timing and control unit.** Generates all timing and control signals — ALE, RD', WR', IO/M', S0, S1 — and handles READY, HOLD/HLDA and RESET.

**5. Interrupt control.** Five hardware interrupts: TRAP (non-maskable, highest priority), RST 7.5, RST 6.5, RST 5.5 and INTR, plus INTA' output.

**6. Serial I/O control.** SID and SOD pins, accessed through RIM and SIM.

**7. Address and data buffers.** A8–A15 carry the high address byte; AD0–AD7 are multiplexed (address in T1, data afterwards), separated externally using ALE.

**Flag register (S Z – AC – P – CY).** S: bit 7 of the result. Z: result zero. AC: carry from bit 3 to bit 4, used for BCD (DAA). P: even parity of the result. CY: carry or borrow out of bit 7. Flags are tested by conditional jump, call and return instructions.

</details>
