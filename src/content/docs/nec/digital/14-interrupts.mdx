## 1. What an interrupt is

An **interrupt** is a signal that makes the CPU pause its current program, run an **interrupt service routine (ISR)**, and then resume. Like an event handler — the device calls you, rather than you polling the device.

**Servicing sequence:**
1. The CPU finishes the current instruction.
2. It checks whether the interrupt is enabled/unmasked.
3. It pushes the **PC onto the stack** (the 8086 also pushes flags and CS).
4. It loads the **vector address** of the ISR into PC.
5. The ISR runs (saving any registers it uses with PUSH).
6. **RET** (8085) or **IRET** (8086) pops the return address; the program resumes.

**Classifications:**
- **Hardware** (a pin) vs **software** (an instruction, e.g. RST n, INT n).
- **Maskable** (can be disabled) vs **non-maskable** (cannot — for emergencies such as power failure).
- **Vectored** (fixed ISR address) vs **non-vectored** (the device supplies the address).
- Edge- vs level-triggered.

## 2. 8085 interrupts

| Interrupt | Priority | Vector | Maskable? | Trigger |
| --- | --- | --- | --- | --- |
| **TRAP** (RST 4.5) | 1 (highest) | **0024H** | **No** | edge **and** level |
| RST 7.5 | 2 | **003CH** | yes | rising edge (latched) |
| RST 6.5 | 3 | **0034H** | yes | level |
| RST 5.5 | 4 | **002CH** | yes | level |
| INTR | 5 (lowest) | non-vectored | yes | level; device puts RST n / CALL on the bus after INTA' |

Vector rule: **RST n → n × 8** in hex. RST 7.5 → 7.5 × 8 = 60 = 3CH; RST 5.5 → 44 = 2CH; TRAP = RST 4.5 → 36 = 24H.

**Software interrupts RST 0–RST 7:** one-byte calls to 0000H, 0008H, 0010H, … 0038H (n × 8). RST 0 = 0000H, the reset address.

**Control instructions:**
- **EI / DI** — enable/disable all maskable interrupts (not TRAP).
- **SIM** (set interrupt mask): the accumulator bits mask RST 7.5/6.5/5.5 individually, reset the RST 7.5 latch, and send serial output on SOD.
- **RIM** (read interrupt mask): reads masks, pending interrupts and the SID serial input into A.

## 3. 8086 interrupts

- **256 interrupt types** (0–255).
- **Interrupt vector table (IVT)** in the first **1 KB of memory: 00000H–003FFH**. Each entry is 4 bytes — new IP (2 bytes) then new CS (2 bytes).
- **Vector address for type n = 4 × n.** Type 2 → 00008H; type 21H → 84H.
- On an interrupt the 8086 pushes **flags, CS, IP**, clears IF and TF, then loads CS:IP from the IVT. **IRET** restores all three.

Predefined types:

| Type | Meaning |
| --- | --- |
| 0 | divide error |
| 1 | single step (TF = 1) |
| 2 | **NMI** (non-maskable pin) |
| 3 | breakpoint (one-byte INT 3 — debuggers) |
| 4 | overflow (INTO with OF = 1) |
| 5–31 | reserved by Intel |
| 32–255 | available to users (INT n), e.g. DOS INT 21H |

Hardware pins: **NMI** (non-maskable) and **INTR** (maskable through IF, with STI/CLI).

## 4. The 8259 programmable interrupt controller

One INTR pin isn't enough for many devices. The **8259 PIC** accepts **8 interrupt requests (IR0–IR7)**, resolves priority (fixed or rotating), masks individual lines, and gives the CPU the vector. **Cascaded** — one master plus up to 8 slaves — it handles **64** interrupt inputs. The PC's classic IRQ0–IRQ15 came from two cascaded 8259s.
