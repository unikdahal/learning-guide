This course covers **NEC 7.3–7.4** and **Lok Sewa Computer Engineer unit 9 (database management systems)**. For **Computer Officer**, DBMS is the single biggest Paper II topic (about **14%**) and comes with hand-written SQL — so this course is worth twice its time.

<Aside type="note" title="Exam form, not production form">
You work with query engines and table formats daily, so the concepts are familiar. The exam wants the **textbook vocabulary** (three-schema architecture, weak entity, BCNF, conflict serializability, write-ahead log), **hand procedures** (attribute closure, candidate keys, decomposition, precedence graphs, undo/redo lists) and **SQL written on paper** without a console to catch mistakes.
</Aside>

## The path

| # | Lesson | Exam skill |

| 1 | [Data models and ER design](/learning-guide/nec/dbms/01-models-er/) | three-schema architecture, independence, ER diagrams, mapping ER to tables |
