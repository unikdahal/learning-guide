This course assumes you know **nothing** about electricity or electronics. Each lesson builds only on the ones before it. By the end you'll be able to answer every kind of question NEC Chapter 1 asks, and write the short Lok Sewa answers for Computer Engineer unit 4.

## How to study one lesson (about 45–60 minutes)

1. **Read the idea section slowly.** Don't memorise yet — make sure each sentence makes sense.
2. **Work the examples with a pen.** Cover the solution, try it, then check.
3. **Read "Traps".** These are the places MCQs try to catch you.
4. **Do "Check yourself"** without looking back. Open each answer only after choosing.
5. **Write misses in your error log** (a notebook page: question, your answer, why it was wrong).

<Aside type="tip" title="One rule">
If an idea isn't clear, stop and re-read the previous lesson. In electronics, almost every confusion comes from a gap one step earlier.
</Aside>

## What you need

A notebook, a pen and a basic calculator (Lok Sewa doesn't allow one, so practise mental arithmetic too). No prior physics is assumed beyond school arithmetic.
