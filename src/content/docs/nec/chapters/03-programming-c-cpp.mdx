## Exam traps

- **Pointer size** depends on the architecture, not the pointed-to type: typically 4 bytes on 32-bit, 8 on 64-bit. On a 16-bit (Turbo C) model, 2 bytes — read the question's assumptions.
- `sizeof(char)` is always 1. A string literal `"abc"` occupies 4 bytes (null terminator).
- A **union**'s size is its largest member (plus padding); a structure's is at least the sum.
- `printf` format specifiers: `%d` int, `%u` unsigned, `%ld` long, `%f` float/double, `%c` char, `%s` string, `%p` pointer, `%x` hex, `%o` octal, `%e` scientific.
- Storage classes: `auto`, `register`, `static`, `extern`.
- File modes: `"r"`, `"w"` (truncates), `"a"`, plus `+` and `b`. Random access: `fseek`, `ftell`, `rewind`.
- **Indirect recursion:** A calls B, and B calls A.
- Default access: `private` in a `class`, `public` in a `struct`. `protected` = class and derived classes.
- A **friend** function is declared inside the class with the `friend` keyword but is not a member.
- `virtual` in the base enables runtime (dynamic) binding. `virtual void f() = 0;` is pure virtual and makes the class abstract.
- **Overriding** = same signature in the derived class, chosen at runtime via virtual. **Overloading** = same name, different parameters, chosen at compile time.
- **Multipath (diamond) inheritance** duplicates the base; a `virtual` base class fixes it.
- Constructors run base → derived; destructors run derived → base.
- Streams: `ifstream` reads, `ofstream` writes, `fstream` does both. Manipulators: `setw`, `setprecision`, `setfill`, `endl`.
- STL: sequence containers (`vector`, `list`, `deque`), associative (`set`, `map`, `multiset`, `multimap`), adapters (`stack`, `queue`, `priority_queue`); iterators connect containers to algorithms.
- An uncaught exception calls `std::terminate()` (which aborts by default). `catch (...)` catches everything; `throw;` rethrows.
