## How it differs from Computer Engineer

- No electrical, electronics, digital design, communications, AI, theory of computation or graphics.
- Adds computer fundamentals, system analysis & design (with JAD), e-commerce, MIS and web engineering, and IT in Nepal (policy and laws).
- Has an extra **practical test** after the written stage, so plan for a possible extra trip.
- Paper I Part I (general awareness and reasoning) is the same as for Computer Engineer.

## What NEC doesn't give you

1. IT in Nepal — acts, policies, institutions (also useful for CE technical writing).
2. E-commerce and e-governance (also CE unit 15.10).
3. MIS, ERP, DSS and web engineering.
4. ~~System analysis & design in its PSC form~~ — now covered: JAD roles, DFD levels and feasibility types in the [software engineering course](/learning-guide/nec/se/00-start-here/).
5. Compiler design (shared with CE).
6. Computer fundamentals and practical-test skills.

About two-thirds of this list also helps the Computer Engineer paper (compiler, e-commerce, SAD for the case study, IT in Nepal for technical writing), so Computer Officer prep is mostly a by-product of Computer Engineer prep.

Written practice for the shared units is in the [answer bank](/learning-guide/lok-sewa/computer-engineer/answer-bank/) (the ★ CO 2083 questions are Computer Officer papers).
